# Grammar of Graphics and Plotnine (Python ggplot2)

Course Project – ES-114: Probability, Statistics and Data Visualization
Indian Institute of Technology, Gandhinagar – 2025

This project serves as a comprehensive guide to understanding the theoretical foundation of the **Grammar of Graphics** and its practical implementation using **Plotnine**, a Python library inspired by **ggplot2** in R.

## 📌 Overview

This documetation aims to:

- Introduce the key principles of the Grammar of Graphics.
- Demonstrate how to build complex data visualizations by layering components.
- Provide hands-on examples using Plotnine in Python.
- Serve as a learning resource for data scientists and analysts transitioning from R to Python.
